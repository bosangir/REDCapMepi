03Setting up the class demonstration project (20 November 2026)

Create this project before the class. We use it to show how a longitudinal study is set up and to explore other advanced features.

  1. Log in to your REDCap account at redcap.uantwerpen.be.
  2. Go to New Project and complete Create a new REDCap Project:
    • Project title: longitudinal studies demo – s2######, where s2###### is your student number
    • Project’s purpose: Practice / Just for fun
    • Project creation option: Upload a REDCap project XML file
    • Choose TBCARE_2026_REDCap_project.xml
  3. Request the project.
